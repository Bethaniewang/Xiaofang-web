# Side By Side Design System

## Mood

Calm, premium, warm, and trustworthy. The interface should feel spacious and
supportive: polished enough for a professional practice without becoming cold
or clinical.

## Colors

- `cream`: warm page background
- `linen`: softly differentiated section background
- `sand`: soft beige card and accent background
- `teal`: primary brand color for headings and actions
- `teal-dark`: deep footer and high-contrast surfaces
- `sage`: quiet botanical accent
- `terracotta`: restrained warm accent for eyebrow text

## Typography

- Headings use an elegant serif stack: Georgia, Cambria, Times New Roman.
- Body text and controls use a clean system sans-serif stack.
- Headings are expressive and lightly weighted. Body copy uses relaxed line
  height for readability.

## Components

- Use rounded cards with fine borders and subtle shadows.
- Use generous vertical spacing between sections.
- Keep buttons pill-shaped with clear focus states.
- Prefer soft organic background shapes over photography when no original
  imagery is available.
- Preserve readable contrast and mobile-first layouts.
